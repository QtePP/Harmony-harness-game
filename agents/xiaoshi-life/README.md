# 如果 · 小狮日记

《如果》是一个**可以改写一页**的人生模拟。玩家扮演小狮，从 2016 年、18 岁的志愿表开始，
到 2033 年、35 岁的同学会结束。每一章都有一个“当年”和两三个“如果”；
每个“如果”都是一笔欲望的账——得到一样，失去一样。

引擎是随载荷分发的 `@ohos/dsh-life` 插件；模型只做叙述。

## 六个结局

标准答案 / 远方的答案 / 被爱的答案 / 野心的答案 / 回家的答案 / 自己的答案。

结局由六个数值和欲望账本决定，不由模型决定。条件不公开——玩家自己走。

## 三个工具

| 工具 | 用途 |
|---|---|
| `life_new` | 开一本新的（会覆盖存档） |
| `life_status` | 看当前章节、数值、城市/学校/工作/伴侣、欲望账本 |
| `life_choose` | 选一个已声明选项（option id，不是序号） |

每次 `life_choose` 返回下一章或结局，不需要再补一次 `life_status`。

## 怎么玩

1. 新建项目「人生之书」，把 [BOOTSTRAP.md](BOOTSTRAP.md) 两条 `---` 之间的整段粘进去。
2. 模型落盘 `AGENTS.md` / 两个技能 / `cards/life.card.json`，然后直接调 `life_new` 开始。
3. 每章选一个；选完模型讲下一章，卡面/工具输出给数值。
4. 想重开另一条如果：说“重开，这次我想选考古”。

## 离线卡片 demo

不想装 App / 不想配 Key：打开 [`demo/life.html`](../../demo/life.html)，4:6 单卡，零依赖，
点「本机推演」可以按钱 / 自由 / 被爱 / 被期待 / 自己五种倾向自动走完一生。

## 边界

- 五章 5 个节点，**不是开放世界**；每个节点五到六个选项，共 3750 条路径。
- 数值是相对刻度（0–100），不是真实收入/寿命预测。
- 小狮、临江、阿远、老周、小满都是虚构；不映射任何真实公司或人物。
- 没有 NPC 对话工具；人物由模型基于 canon 叙述，不落状态。
