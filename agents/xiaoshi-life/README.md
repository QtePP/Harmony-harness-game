# 如果 · 小狮日记

《如果》是一本可以改写一页的人生之书。小狮 1985 年出生在广东东莞，2003 年十八岁，
2026 年四十一岁。**九页**：六次人生选择，三次拷问。**七十种结局**：五个主题 × 六个代价位，再加三十种由具体人生链触发的特殊结局和十种「潦草人生」。

每个“如果”都是一笔欲望的账——得到一样，失去一样。前一步决定后一步哪条路存在：
你读了什么学校，才有什么第一份工作；你在拷问里承认了什么，四十岁才有什么路可走。

引擎是随载荷分发的 `@ohos/dsh-life` 插件；模型只做叙述。

## 七十种结局

五个主题：**钱 / 自由 / 爱 / 家 / 自己**。
六个代价位：**身体 / 关系 / 自由 / 亲情 / 钱 / 遗憾 / 圆满**（主题自己的那一项不算代价）。

引擎先算“这一生最后被什么定义”，再算“主题之外最塌的那一项”，拼成
`主题-代价`，例如 `money-health` = 金手铐、`self-none` = 自己的答案。
特殊结局由具体选择链触发（去找阿远、重新读书、回东莞造船、办画展、写第一本书、开诊所、当教练、守柜台……），
优先于主题 × 代价；矩阵结局仍然是大多数人生的落点。

另有一条**开放式尾声**：城市、工作、身边的人、身体、父母、遗憾，六个碎片每次不同；
玩家还可以在结局卡上写一句“你的如果”。

## 三个工具

| 工具 | 用途 |
|---|---|
| `life_new` | 开一本新的（会覆盖存档） |
| `life_status` | 看当前页、年份、数值、城市/学校/工作/伴侣、欲望账本、可走与锁住的路 |
| `life_choose` | 选一个已声明选项（option id，不是序号）；锁住的选项会报出原因 |

每次 `life_choose` 返回下一页或结局，不需要再补一次 `life_status`。

## 三条规则

1. **复利**：同一种欲望每选一次，下一次同类收益 ×1.12。早期选择会放大到后期。
2. **锁路**：`requires` 不满足的选项仍然显示，但走不了，并给出原因（“你当年没学金融”）。
3. **拷问**：三次拷问不改变数值，只改变十多年后哪条路存在。Q3 的三个答案分别打开
   “找阿远 / 重新读书 / 把这一步走完”。

## 怎么玩

1. 新建项目「如果」，把 [BOOTSTRAP.md](BOOTSTRAP.md) 两条 `---` 之间的整段粘进去。
2. 模型落盘 `AGENTS.md` / 两个技能 / `cards/life.card.json`，然后直接调 `life_new` 开始。
3. 每页选一个；选完模型讲下一页，卡面/工具输出给数值。
4. 想重开另一条如果：说“重开，这次我想选海洋”。

## 离线卡片 demo

不想装 App / 不想配 Key：打开 [`demo/life.html`](../../demo/life.html)，4:6 单卡，零依赖。
点「本机决策」会按钱 / 自由 / 被爱 / 被期待 / 自己 / 平衡六种倾向，往前推演到结局再回头选这一步；
每一步都会写出“为什么这样选”。

## 边界

- 九页，**不是开放世界**；每页的选项数随前置选择变化，共 **4,959,918** 条路径（含锁住的）。
- 数值是相对刻度（0–100），不是真实收入/寿命预测。
- 小狮、东莞、阿远、老周、小满都是虚构；真实的年代符号只做氛围，不映射任何真实公司或人物。
- 没有 NPC 对话工具；人物由模型基于 canon 叙述，不落状态。
