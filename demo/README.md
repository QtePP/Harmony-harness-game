# 三国人生 · 离线 demo

在线试玩：

- 三国 · 长页版：<https://qtepp.github.io/Harmony-harness-game/demo/sanguo.html>
- 三国 · 4:6 卡片版：<https://qtepp.github.io/Harmony-harness-game/demo/card.html>
- 如果 · 竖版卡片版：<https://qtepp.github.io/Harmony-harness-game/demo/life.html>
- 穿梭人生 · 副本：<https://qtepp.github.io/Harmony-harness-game/demo/life.html#copybook>

本地：

```bash
open demo/sanguo.html          # 三国 · 长页版
open demo/card.html            # 三国 · 4:6 单卡版
open demo/life.html            # 如果 · 竖版单卡
open demo/life.html#copybook    # 穿梭人生 · 副本（同一份 HTML）
# 或者直接把文件拖进浏览器
```

三个都是**单文件**：不需要安装 App、不需要 API Key、不需要网络、不需要 Node。
三国两个约 105 KB，人生之书（含 50 个副本）约 618 KB；页面没有任何外部请求。

## 它是什么

- **引擎是真的**：复用 `host/profile-ohos/.../@ohos/dsh-sanguo/engine/` 的掷骰、判定、
  数值、天下推演；不是为 demo 另写一套。
- **剧情是真的**：`data/acts.json` 的**十二幕 38 个场景**，从涿郡桑树到白帝托孤。
  第八至十二幕（赤壁 / 益州 / 汉中 / 荆州 / 白帝）是这次补齐的正式场景，同一套引擎直接吃。
- **结局是 demo 层**：引擎走到白帝之后 `act = "end"`；demo 读取第十一幕「称帝」、
  第十二幕「夷陵」「白帝」的关键选择（写进 `state.flags`）与末局数值，收束到 8 个结局。
- **本机推演**：不调用模型。它把每个选项的 effects 乘上一组透明权重（仁 / 霸 / 稳 / 隐），
  再加一点随机；点「本机推演」就会按这个倾向自动走完一生。

> 这不是 App 里那个 pybot。pybot 是藏在 WebView / Pyodide 里的 Hugging Face 模型
> （冷启 ~26s、常驻 ~648MB），没法在 `file://` 的单文件 HTML 里跑。这里用「引擎 + 透明权重」
> 达到同样的目的：离线、即时、可解释。要真上小型神经网络，得离线训练再把权重嵌进来，
> 对这个体量的文本不值得。

## 三个版本

| 文件 | 形态 | 说明 |
|---|---|---|
| `sanguo.html` | 长页 | 场景、数值、选项纵向排列；适合阅读和手机滚动 |
| `card.html` | 三国 · 4:6 单卡 | 4 列 × 6 行的竖版卡；卡内完成选择/判定/继续，卡外只有推演、倾向、图鉴、重开 |
| `life.html#copybook` | 穿梭人生 · 副本 | 50 个独立人生副本；和《如果》在同一个 HTML 里，结局页会按这一世推荐 3 个副本，副本库支持「模拟体验」 |
| `life.html` | 如果 · 竖版单卡 | 九页（六次选择 + 三次拷问 + 五段分支事件）、七十种答案；大屏保持 4:6，手机上卡片加高到 600px，正文 14.5–15px、选项 13–14.5px；锁住的路可点开看原因 |

两版共用 `game.js` / `endings.js` / `policy.js`，存档与结局图鉴共用同一组
`localStorage` key，所以在一个版本里解锁的结局，另一个版本能看到。

## 三国：8 个结局

关键选择：

- 第十一幕 `emperor`：`crown`（称帝）/ `decline`（不称帝）/ `king`（只称汉中王）
- 第十二幕 `yiling`：`war`（亲征伐吴）/ `peace`（不出兵）
- 第十二幕 `baidi`：`trust_zhuge`（托孤诸葛亮）/ `trust_liyan`（托孤李严）/ `retire`（散尽家财回涿郡）

| id | 标题 | 条件 |
|---|---|---|
| `zhaolie` | 昭烈 | 称帝，名望 ≥ 70、信义 ≥ 55、势 ≤ 35，且未伐吴 |
| `dufu` | 独夫 | 称帝，但上面任一条不够 |
| `renzhe` | 仁者 | 不称帝，信义 ≥ 65 |
| `pianan` | 偏安 | 不称帝，信义 < 65 |
| `hanzhong` | 汉中王 | 只称汉中王，不称帝 |
| `zhixi` | 织席者 | 在 `baidi` 选「散尽家财回涿郡」（`retire`） |
| `zaoshi` | 蚤世 | 体力 ≤ 15；或伐吴后体力 ≤ 35 |
| `jiedi` | 举世皆敌 | 伐吴，体力 > 35 |

优先级：体力 ≤ 15 → `zaoshi`；`retire` → `zhixi`；`war` → `zaoshi`/`jiedi`；
否则按称帝/不称帝/称王分流。所有分支都有落点。

结局图鉴存在浏览器 `localStorage`（`sanguo-demo-endings-v1`）；中途存档用
`sanguo-demo-run-v1`，刷新后可以从开场页「继续上局」。

## 如果：七十种答案

`life.html` 是同一套「引擎 + 卡片」做的人生模拟：小狮 1985 年出生在广东东莞，
2003 年十八岁，2026 年四十一岁。**九页**：六次人生选择 + 三次拷问。
六个数值是钱 / 健康 / 爱 / 自由 / 父母 / 遗憾。

- **前置锁路**：你读了什么学校，才有什么第一份工作；拷问里承认了什么，四十岁才有什么路。
  锁住的路不隐藏，点「当年没走的路」能看到每一条的原因。
- **复利**：同一种欲望每选一次，下一次同类收益 ×1.12；卡面会显示「复利 ×1.24」。
- **七十种结局**：五个主题（钱 / 自由 / 爱 / 家 / 自己）× 六个代价位（身体 / 关系 / 自由 /
  亲情 / 钱 / 遗憾 / 圆满），再加 30 种由具体人生链触发的特殊结局和 10 种「潦草人生」。结局图鉴分七组，只给锁住格子的提示。
- **开放式尾声**：城市、工作、身边的人、身体、父母、遗憾六个碎片每次不同；
  还能在结局卡上写一句自己的「如果」。
- **本机决策**：不调用模型。对每个可走选项往前推演到 2026，再回头选这一步；每一步都写出理由。

`npm run simulate` 只验三国；人生之书的 **4,617,684** 条路径和 70 个结局在
`@ohos/dsh-life/test/life.test.mjs` 里穷举验。

## 边界

- 十二幕（38 个场景）都已写进 `acts.json`；引擎不用改。第八至十二幕的数值尺度按后期
  （名望/信义可到 100，兵力可到数百）设定，和前期不完全同一把尺子。
- 结局文本、8 个结局的判定、`flags` 映射都在 demo 层；手机 App 里没有这套结局 UI，
  引擎只负责算到白帝为止。
- 没有音频、图片、动画资产；所有观感来自 CSS 与排版。
- 没有把存档导出成 `.sanguo/save.json` 的入口；demo 的存档只活在 localStorage。
- 许可与仓库一致：MIT。剧情来自史书与演义，属公有领域。
